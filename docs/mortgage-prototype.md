# Короткая ипотечная анкета

Кликабельный мобильный прототип по [заданию](../tasks/mortgage-short-form/task.md). Открывается на `/` и `/mortgage`. Использует React, CSS Modules, Lato и существующие токены/компоненты Циана. Зависимости и способ запуска не изменены: `npm ci`, `npm run dev`.

## Сценарий

1. Калькулятор: программа, тип квартиры, стоимость, первоначальный взнос и срок; платёж пересчитывается. Кнопка «Подобрать ипотеку» открывает анкету.
2. Ваши планы: срок покупки, наличие квартиры, помощь консультанта. Последний вопрос показывается при семейной программе **или** новостройке.
3. Бюджет: доход с быстрыми вариантами суммы, наличие кредитов, их общий месячный платёж при ответе «Да».
4. Контакты: имя и почта редактируются, подтверждённый телефон доступен только для чтения.
5. Звонок: один из трёх ближайших дней, время по Москве, согласия. Реклама выключена по умолчанию; при ранее данном согласии повторный вопрос отсутствует.
6. Успех: выбранные дата, время и телефон, объяснение следующих действий партнёра.

Шаги анкеты имеют индикатор прогресса. Ответы сохраняются в памяти страницы при переходах назад и выходе к калькулятору. После перезагрузки сбрасываются. Данные никуда не отправляются и не сохраняются в localStorage. Отправка имитируется, повторный клик блокируется. После возвращения к расчёту с экрана успеха начинается новая анкета.

## Дизайн

Светлый мобильный интерфейс с одной основной кнопкой внизу и прокручиваемой областью вопросов. На десктопе прототип остаётся узким; рядом — поясняющая область с архитектурной иллюстрацией. На телефоне интерфейс занимает экран. Основное выравнивание слева, варианты выбора имеют площадь нажатия от 44px.

Палитра взята из существующих семантических токенов: синий `#006cfd`, текст `#0d162e`, белый `#ffffff`, фон `#f3f5fa`, выделение `#e6f0ff`, подтверждение `#227e01`. Lato 400/600/700, заголовки мобильных экранов 29px, основной текст 14–16px. Индикатор платежа использует табличные цифры. Движение ограничено обратной связью на нажатия и индикатором загрузки; `prefers-reduced-motion` учитывается.

Вместо длинного списка банковских вопросов — четыре смысловых шага с условными полями. Иллюстрация относится к будущему дому, а визуальный акцент калькулятора — к рассчитанному платежу. Каталог UI сохранён по `/ui-kit`.

## Учебные допущения

- Данные Анны Ивановой, телефон и почта — вымышленные примеры.
- Ставки 6% и 18% служат только для демонстрационного расчёта, не описывают текущие банковские предложения. Проверки соответствия программе и расчёта одобрения нет. Программу и тип объекта можно сочетать для проверки условного вопроса; фактическую доступность должен проверять реальный сервис.
- Ближайшие три дня — завтра и два следующих календарных дня по Москве, включая выходные. Время 10:00, 12:00, 14:00, 16:00 и 18:00 — демонстрационные слоты, без проверки календаря партнёра.
- Имя и фамилия обязательны, отчество допускается не указывать. Доход и сумма существующих платежей должны быть положительными; оценку платёжеспособности прототип не делает.
- Тексты согласий — учебные примеры; реальный партнёр, окончательные юридические документы и интеграция требуют уточнения.

## Проверка состояний

Кнопка с ползунками справа в шапке калькулятора открывает «Сценарии прототипа». На десктопе есть также кнопка «Сценарии» слева.

- «Имя и почта пустые» оставляет подтверждённый телефон, очищает редактируемые контакты.
- «Согласие на рекламу уже дано» убирает повторный вопрос о рекламе.
- «Ошибка при первой отправке» сохраняет заполненную анкету и предлагает повторить отправку; следующая попытка успешна.
- Применение сценария начинает анкету заново. Пропуск обязательных ответов показывает ошибки. Базовая программа со вторичкой скрывает вопрос о подборе квартиры; ответ «Нет» по кредитам очищает скрытый платёж.

Автоматические проверки: `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`, `npm run verify:snapshot`. Поведение покрывается тестами в `src/pages/mortgage/`. Ручная проверка — проход от калькулятора до успеха на мобильном экране, переходы назад, пустой профиль и повторная отправка.
