# Проверка подготовки · 16 ноября 2026

Окружение: macOS, Node.js 24 и 25; автоматические проверки — TypeScript, ESLint, Vitest + Testing Library, Vite. Проверка снимка: 526 токенов, 5 режимов, 24 SVG и 292 исходных файла.

Каталог проверен в браузере на 1440 × 1000 и 390 × 844: светлая и тёмная темы, варианты кнопок, поля, выбор, диалог. Escape закрывает диалог, фокус сначала переходит в поле и затем возвращается на открывшую кнопку. Горизонтального скролла на мобильном экране нет.

Пять тестов UI проверяют блокировку кнопки при загрузке, подписи и ошибки полей, нативный выбор, фокус и закрытие диалога, подсказку и Escape.

Снимки: [desktop](ui-desktop.jpg), [mobile](ui-mobile.jpg), [тёмная тема](ui-dark.jpg). Это скриншоты учебного каталога, а не боевого сайта.

## Ипотечная анкета · 21 ноября 2026

Реализация в ветке `pashex/mortgage-short-form`. [Описание сценария и учебных допущений](../mortgage-prototype.md).

Проверки `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`, `npm run verify:snapshot` прошли. Всего 12 тестов: 5 существующих тестов UI и 7 новых. Новые проверки покрывают весь путь анкеты, возврат назад, обязательные поля, пустой профиль, исправление ошибок без потери фокуса, условный подбор квартиры и платёж по кредитам, ранее данное рекламное согласие, повторную отправку, расчёт платежа и смену года в календаре.

В браузере пройден путь от калькулятора до успеха с семейной ипотекой, подбором квартиры и действующим кредитом. Проверены блокировка формы на время отправки, диалог согласий, дата/время/телефон на экране успеха и возвращение к расчёту. При открытии анкеты ошибки не показываются. Обязательные согласия видны в закреплённой области отправки. Ссылка на `/ui-kit` и возврат к прототипу работают, ошибок в консоли не обнаружено.

Визуально проверены 390 × 844, 320 × 740 и 1280 × 900. На мобильных размерах ширина документа совпадает с шириной экрана; длинное содержимое прокручивается между шапкой и основной кнопкой. Проверка на физическом устройстве с экранной клавиатурой не выполнялась.
